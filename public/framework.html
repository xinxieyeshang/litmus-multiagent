LITMUS: Multi-Signal Framework for Predicting Paper Impact

A four-signal computational approach to identifying high-impact research in biomedical literature, validated against F1000Prime expert curation.

Data Input

Paper Corpus

PMID Title Abstract MeSH Terms Year
N = 3,100 Nature-indexed biomedical papers
Distribute to four signals
Signal Computation
🧠
SIGNAL 1
LLM Impact
Assessment
5-dimension evaluation:
  • Transformative potential
  • Broad relevance
  • Methodological significance
  • Clinical/translational impact
  • Paradigm challenge
Model: Doubao Seed / DeepSeek V3
S1 ∈ [0, 1]
🌐
SIGNAL 2
MeSH Topic
Breadth
Tree-number classification:
  • Query NLM MeSH API
  • Map to 8 major categories (A–V)
  • Count unique domain coverage
  • MeSH=0 → fixed 0.25 (de-bias)
Source: id.nlm.nih.gov/mesh/
S2 = domains / 8
🕸
SIGNAL 3
Knowledge
Bridging
Bipartite network analysis:
  • TF-IDF + TextRank keywords
  • Paper–keyword bipartite graph
  • Brandes betweenness centrality
  • Cross-domain connectivity
Type: Pure computation
S3 = norm(BC)
💡
SIGNAL 4
Cognitive
Deviation
Dual-component novelty:
  • Semantic deviation (internal):
    1 − mean cos(vi, vj)
  • Concept rarity (frequency):
    low-freq MeSH ratio
Embedding: coze-coding-dev-sdk
S4 = 0.5D + 0.5F
Aggregate scores
Score Fusion

Degenerate signal detection → auto re-weight (weight = 0 if all values identical)
